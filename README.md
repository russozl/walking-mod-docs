# Walking Mod - Tutorials

Guides for the Realistic Walking Camera mod for Assetto Corsa.

## Changelog

- [Full changelog](CHANGELOG.md) - every change, newest first

## Tutorials

- [Custom Camera Motions](tutorials/custom-motions.md) - Create and import your own handheld camera motions
- [Blender to Walking Mod](tutorials/blender-export.md) - Export camera animations from Blender into the mod
- [Dolly Camera System](tutorials/dolly-system.md) - Create cinematic camera paths in-game
- [Custom Characters](tutorials/custom-characters.md) - Add your own 3D characters and animations

## Requirements

- Assetto Corsa with [Custom Shaders Patch](https://acstuff.net/patch/)
- Realistic Walking Camera mod installed
- Blender 3.0+ (for Blender tutorials)
